# Balancing Growth and Emissions

This repository contains the Quarto (`.qmd`) source file and dataset used for the analysis titled:

***Balancing Growth and Emissions: Lessons from Global CO₂ Reduction Successes for Australian Policy***

The project analyses CO₂ emissions and economic growth trends across Australia and selected peer countries using publicly available data.

---

## Files

* `report.qmd` – Quarto file containing all analysis, visualisations, and written commentary
* `owid-co2-data.csv` – Dataset sourced from Our World in Data

---

## How to Render

To render the report locally:

```r
quarto render report.qmd
```

Ensure the following are installed:

* R
* Quarto
* Required R packages (listed within the QMD file)
